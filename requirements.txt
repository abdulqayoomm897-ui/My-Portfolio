AI-Powered Modern Portfolio Website (Abdul Qayoom Mangi)
1. 📌 Introduction
1.1 Purpose

The purpose of this system is to develop a fully functional, modern, and animated portfolio website for Abdul Qayoom Mangi, an AI & Data Science enthusiast and Software Engineering student.

The platform will dynamically present skills, projects, experience, and services using modern frameworks and backend integration to support career opportunities such as AI internships and freelance work.

1.2 Scope

The system will:

Showcase AI/ML projects (CNN, OpenCV, Data Analysis, etc.)
Display dynamic data fetched from backend (resume-based content)
Provide interactive UI with animations
Offer contact functionality
Highlight services including:
AI Solutions
Mobile App Development (updated)
Data Analysis
Be deployed online using modern platforms

2. 🧠 Overall Description
2.1 Product Perspective

The system is a modern full-stack web application built using:

Frontend: React + Next.js
Styling: Tailwind CSS
Animations: Framer Motion
Backend: Node.js / API routes (Next.js)
Deployment: Vercel
2.2 Product Functions
Dynamic content rendering from backend
Animated UI interactions
Responsive design (mobile-first)
Project showcase
Contact form with backend integration
Resume-based data display
